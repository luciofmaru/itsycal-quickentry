# Privacy policy: Itsycal Personal

Itsycal Personal is a modified copy of the open-source calendar app Itsycal, built and used by one person, the owner of this repository. It isn't offered to anyone else.

## What it accesses
With the owner's permission, the app reads and changes events in the owner's own Google calendars so it can show them and add new ones. A companion backup tool on the owner's own server makes a copy of those calendars.

## Where the data goes
- Calendar data is sent only between Google and the owner's own devices and server.
- Nothing is sold, shared, or sent to anyone else, and the app shows no ads and collects no analytics.
- Sign-in credentials are stored only on the owner's devices (in the macOS Keychain, or in a file only the owner can read on the server).

## Removing access
Access can be withdrawn at any time at https://myaccount.google.com/permissions.
